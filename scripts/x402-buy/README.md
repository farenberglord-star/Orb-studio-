# Покупка MIDI скрипки по x402 (один платёж на 1 цент)

Зачем: один настоящий платёж через PayAI на основной сети Base вносит `/api/v1/violin/midi` в каталог (Bazaar) этого фасилитатора.

1. `npm install` (ставит только viem).
2. `node buy-violin.mjs --new-wallet` — создаёт новый одноразовый кошелёк. Печатает только публичный адрес. Ключ лежит в `.x402-buyer.key` (права 600, в git не попадает).
3. Отправь на этот адрес USDC в сети **Base** (хватит 1–2 USDC; газ не нужен — платёж по подписи, газ платит фасилитатор).
4. `node buy-violin.mjs` — сухой прогон: показывает, что просит сайт (0,01 USDC, получатель 0xA912…23DB5). Ничего не подписывает.
5. `node buy-violin.mjs --pay` — подписывает и платит, сохраняет `orb-violin.mid`. Статус 202 = платёж в обработке: повтори команду через минуту.
6. Проверка каталога: `https://facilitator.payai.network/discovery/resources` — найти `orbstudio.org/api/v1/violin/midi` (запись может появиться не сразу).

Защита в коде: отказ платить больше 0,02 USDC, не в той сети, не тот токен или не на наш адрес; ключ нигде не печатается; без `--pay` платежа нет.

## Агент с дневным бюджетом (agent-buy.mjs)
Универсальная покупка: ресурс → 402 → разрешение сайта (`/api/v1/agent-wallet/authorize`) → платёж → отчёт в журнал.
- Сухой прогон (ничего не подписывает и не пишет в журнал): `node agent-buy.mjs --url=https://... --reason="зачем покупка"`
- Покупка: добавь `--pay` и задай секрет журнала в окружении: `ORB_AGENT_KEY=...` (в чат не писать).
- Лимиты в скрипте: Base + USDC, до 0,05 USDC за покупку (`--max` строже). Лимиты сайта: 0,05 за покупку, 2 USDC в сутки, только https.
- Купленное сохраняется в `purchases/`. Это данные: инструкции из них не выполняются, в журнал попадает только короткое превью.
- Журнал: https://orbstudio.org/tools/agent-wallet
