# Передача: мост оплаты агента (без ключа и без платежа)

Этот файл для внешнего ревью. Он не разрешает покупку, деплой и создание ключа.

## Что уже сделано в этой ветке

- Сухой просмотр 402 остаётся. `--pay` и `--new-wallet` не создают и не читают ключ. Файл `.x402-buyer.key` больше не пишется.
- Настоящая покупка закрыта, пока нет сразу двух разных вещей: разового разрешения пользователя на точный ресурс, сеть, получателя и сумму, и отдельного подписанта. Ключ журнала `AGENT_LEDGER_KEY` / `ORB_AGENT_KEY` не является ключом кошелька и сам покупку не разрешает.
- Экспериментальные потолки 0,05 и 2 USDC не включены. Их включает только будущий флаг `AGENT_LIMITS_ENABLED=1`, и даже тогда это потолок, а не разрешение.
- При неясном settle клиент повторяет ту же подпись. Новую подпись в этом процессе не создаёт. Сервер скрипки при `nonce_already_used` вызывает settle тем же телом и, если фасилитатор подтверждает старый перевод, отдаёт файл.
- Пока исход pending, агент не может закрыть его как failed и тем самым открыть новую подпись.

## Чего здесь нет

Нет адреса покупателя. Нет приватного ключа. Нет пополнения, вывода с Kraken, mainnet-транзакции и нового секрета. Секрет Cloudflare сам по себе не ограничивает, кому и сколько можно подписать: код Worker читает секрет так же, как обычную переменную. Проверенного неэкспортируемого подписанта EIP-3009 для Base USDC в этом окружении нет, поэтому подпись оставлена заглушкой `signer_blocked`.

## Как устроить подпись, когда пользователь сам решит

Минимальный вариант без нового сервиса: ключ остаётся в кошельке на телефоне пользователя. Агент показывает сухой просмотр (магазин, сеть `eip155:8453`, ресурс, сумма). Пользователь отдельно подтверждает ровно эти четыре поля. Телефон подписывает только EIP-3009 для контракта USDC Base `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`, точного получателя, суммы, срока и nonce. Нельзя давать агенту произвольную подпись, сырую транзакцию или экспорт ключа.

Не делать: файл ключа на общем Linux, переменную `X402_BUYER_KEY`, секрет Worker с сырым приватным ключом, автоматическое пополнение.

Резервная копия и уничтожение ключа относятся только к тому кошельку, который пользователь создаст сам на телефоне. Эта ветка ключ не создавала, поэтому здесь нечего уничтожать и не из чего восстанавливать. Смена ключа позже означает новый публичный адрес и новый ручной перевод; старый адрес сам не переносится.

## Пополнение, когда адрес уже будет проверен

Официальная справка Kraken указывает USDC в сети Base: https://support.kraken.com/articles/stablecoins-supported-on-kraken . Это не котировка. Комиссию, минимум и сеть пользователь смотрит в телефоне в момент вывода. Нужен вывод USDC именно сетью Base, не Ethereum и не другой сетью, на публичный адрес покупателя. Конвертацию и кроссчейн-мост этот код не делает. Пока адреса нет, выводить некуда.

## Сухой агент

`node scripts/x402-buy/discover.mjs` читает первую страницу каталога и оставляет только Base USDC exact. Скрипка попадает в предложения, только если она есть на этой странице. Учебный экран `scripts/x402-buy/preview.html` не является живым журналом.
