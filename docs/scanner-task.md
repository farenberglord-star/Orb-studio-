# Задание сканеру (Лиана / Грок / DeepSeek) — короткая версия, 25.11.2026

К этому заданию приложен файл `scanner-known-names.txt`: там все имена, которые у нас уже есть (фамилия и год рождения). **Их не предлагать.** Если фамилия есть в файле, а год рождения другой, это тёзка, его можно.

## Что искать
Учёных, умерших в 1900–2026 годах, у которых есть **названная мера или правило, считающееся на наших данных**. Наши данные: заголовки новостей и издания; время публикации каждого издания; число изданий по одной истории; индексы радаров 0–100 по времени (каждые 30 мин); пропуски (`null`); речевые акты (утверждение, обещание, угроза, требование, событие); измеренные события (магнитуда землетрясений, уровень воды, частота сети, цены, энергопотребление).

## Куда смотреть в первую очередь (в зонах меньше всего карточек)
1. answer_cost — цена ответа и проверки
2. stale_data — устаревшие данные
3. own_limits — границы собственного знания
4. side_effects — побочные эффекты

Остальные зоны (one_model, rumour_vs_fact, measurement_error, look_alike) — только если нашлось очень сильное.

## Что вернуть (строго так, без вступления, без итоговых отчётов)
До 20 имён, по одной строке:

`Имя Фамилия | годы жизни | зона | правило для агента ≤ 20 слов, из его собственной работы (название работы, год) | число: что мерить, из каких наших данных | даты: в (уверена) / с (сомневаюсь)`

После списка — одна строка: какие даты ты не уверена. Больше ничего: не пиши, кого отсеяла, не пиши «заголовок не найден», не пересказывай правила.

## Не предлагать
- военные и медицинские темы, а также работы, выросшие из военных или разведывательных задач (военный эпизод в биографии сам по себе не исключает, если правило из гражданской работы);
- прогнозы и сигналы; слова «первый» и «уникальный»;
- правило, которое следует не из его работы, а из поздней критики;
- имя, чью дату смерти ты не знаешь: лучше пропусти, чем угадывать.

## Как проверяет Клод (чтобы тратить меньше)
Он прогоняет список через `python3 tools/scanner_names.py check`, берёт только новые имена и сверяет только их даты смерти по источнику. Всё, что ты вернёшь сверх формата, он читать не будет.
