Полная история до 24.11.2026 включительно. Новые записи о партиях учёных и построенных мостиках добавлять сюда, в конец нужного раздела; в CLAUDE.md — только правила.

## Библиотека кристаллов: каждая новая партия учёных
- Новых учёных (от Грока и Gemini) добавляй в `tools/crystals_data.py`, затем запусти `python3 tools/crystals.py` целиком (без `| head`, иначе не запишутся de/en-страницы).
- После каждой партии ищи **мостики**: две-три карточки (новые или старые), которые вместе дают то, чего нет ни у одной по отдельности, и что можно измерить нашими данными. Ищи также **мостики между мостиками** (новый мостик, который соединяет уже найденные).
- Для каждого мостика укажи: какие карточки, что он даёт агенту, какие данные нужны, созрел ли он (данные уже есть → предложить датчик) или ждёт (данных или истории нет).
- Найденные мостики (23.11.2026): «усиление при пересказе» (Касперсон + Тоффлер + Ховард + Сёрл — построен датчик get_kasperson 23.11); «тяжёлые хвосты» (Мандельброт + «Счёт попаданий», почти созрел); «тёзки в новостях» (Левенштейн + Гич, Лоу, Баркан Маркус + Уинклер, ждёт базы «кто есть кто»); «опубликованный радар меняет рынок» (Розенталь + Буш + «Счёт попаданий», ждёт месяцев истории).

## Датчики из мостиков (аудит 24.11.2026: 142 мостика, 13 датчиков; владелец сказал «да» на №1 и №2)
- Критерии «мостик → датчик»: есть число из открытого источника по расписанию; оно меняется; агент делает что-то иначе; нет такого датчика; можно проверить задним числом. Без числа — строка паспорта или правило ведущих, не датчик.
- `schmidt` (дерево или волна; Шмидт + Шлейхер + Тард): `src/schmidt.js`, /api/v1/schmidt, get_schmidt. Время подключения каждого издания берётся из `verify` радара (поле `joins`, наружу в /api/v1/radars не выводится) и хранится в `radar_life.joins`. Форма: волна ≥60 % изданий за 30 мин от первого; цепочка ≤⅓ и последнее ≥60 мин; иначе смешанная. Форма — не причина: волна может быть одной лентой агентства. Страницы нет (как у bradford, zipf).
- `cohen_s` (размер случая и размер тревоги; Стэнли Коэн + Касперсон + Осгуд): `src/cohen_s.js`, /api/v1/cohen-s, get_cohen_s. Пока только землетрясения: заголовок сопоставляется с USGS (2.5_week) по месту; громкий = сильное слово или ≥5 изданий; «громко для размера» = громкий при магистуде <5,5. Магнитуда — не ущерб; нераспознанное место считается «не измерено», а не громким. Другие события — когда найдём такую же измеренную меру (GDACS даёт только оранжевые и красные).
- Мостики `tree_or_wave` и `moral_panic` в `crystal_bridges.js` теперь sensor с полем `number`; карточки `schmidt_j`, `cohen_s` — covered. Страниц для людей и записи в портал «в честь учёных» нет: это только API и MCP. Эфир — только с «да» владельца.
