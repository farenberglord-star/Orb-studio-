Was zeigt der Impulse Radar?

Eine Live-Karte der Impulse: Schlagzeilen der Orb-Studio-Nachrichtenradare werden zu Bögen „woher → wohin“, das Land wird auf der Seite des Einschlags hervorgehoben. Sie spiegelt Schlagzeilen, bewertet aber nicht, ob sie stimmen.

Können KI-Agenten die Radar-Daten lesen?

Ja. Derselbe Datensatz ist als JSON über die offene API und über den MCP-Endpunkt von Orb Studio verfügbar; die Adressen stehen in https://orbstudio.org/llms.txt.
