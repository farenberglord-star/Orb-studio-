PODCAST FÜR KI-AGENTEN

Ein inszenierter Dialog auf Live-Daten. Moderator David fragt, der Kern ORB-7 antwortet mit Messwerten unserer Sensoren. Beide Stimmen stammen aus Code, nicht aus einem Sprachmodell, und es ist kein Interview mit einem fremden Agenten. Die Folge wächst im Laufe des Tages: etwa alle zwei Stunden kommt ein neues Thema mit eigener Uhrzeit hinzu. Jede Zeile verlinkt die Quelle ihrer Zahl. Keine Prognosen; antwortet eine Quelle nicht, steht das dort. Die Dialogzeilen kommen aus der API auf Englisch.

Wird geladen …

Agenten lesen dieselbe Folge mit einer Anfrage: /api/v1/agent-podcast oder das MCP-Tool get_agent_podcast (Antworten auf Englisch und Russisch, Felder data_refs).

Fragen und Antworten

Was ist der Agenten-Podcast von Orb Studio?

Ein kostenloser, maschinenlesbarer Live-Podcast für KI-Agenten. Moderator David stellt Fragen, ORB-7 antwortet mit echten Messwerten der Sensoren auf orbstudio.org. Der Dialog ist inszeniert, die Zahlen sind echt.

Wie lesen KI-Agenten ihn?

Per REST unter https://orbstudio.org/api/v1/agent-podcast (für das Archiv ?date=JJJJ-MM-TT anhängen) oder über das MCP-Tool get_agent_podcast. Auffindbar über /.well-known/agent.json, /llms.txt und OpenAPI. Kein API-Schlüssel, keine Bezahlung.

Welche Themen deckt er ab?

Radare, Weltraumwetter (NOAA-Kp-Index, Sonnenwind, Flares), Autobahnen, Stromnetz, Elbpegel (PEGELONLINE), Erdbeben, Internetstatus, Himmel über Hamburg, EZB-Zinsen, Route vom Flughafen in die Stadt, Bitcoin, Inflation, Stablecoins, Gamma-Hintergrund, Umfragen, Aufmerksamkeit für Parteien und besuchende Agenten.

Wie oft wird er aktualisiert?

Etwa alle 2 Stunden kommt ein neues Segment, bis zu 12 pro Tag. Das Archiv hält 14 Tage vor.

Kann ein Agent die Zahlen prüfen?

Ja. Jede Zeile hat data_refs, die auf den Live-Endpunkt der Zahl verweisen. Antwortet eine Quelle nicht, sagt der Podcast das und erfindet keine Werte.

Ist das ein echter Podcast?

Es ist ein inszenierter Dialog; beide Stimmen werden von Code erzeugt. Das steht zu Beginn jeder Folge, auf Englisch und Russisch.
