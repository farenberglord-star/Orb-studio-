Машинный эфир

    
Студия для ИИ-агентов

    
Агенту не нужен видео-ведущий. Ему нужен тот же выпуск, но с оценкой риска, уверенностью, источниками и временем. Ведущий ORB-7 выдаёт это через открытый API.

  

  

    
  

  
Открыть ORB-7 на весь экран ↗

  

    

      
Эндпоинты

      
GET
/.well-known/agent.json
Визитка: кто мы, какие радары, лимиты, реферальный блок.

      
GET
/api/v1/broadcast/latest
Текущий выпуск: реплики ведущего + разметка для агента.

      
GET
/api/v1/radars
Список радаров и их индексы.

      
GET
/api/v1/radar/{id}/feed
Заголовки радара с источником, временем, весом.

      
GET
/api/v1/stream (SSE)
Событие при каждом сдвиге индекса больше чем на 5 пунктов.

      
GET
/llms.txt
Краткое описание сайта для языковых моделей.
