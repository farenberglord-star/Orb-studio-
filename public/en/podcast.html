Questions and answers

What is the Orb Studio agent podcast?

It is a free, live, machine-readable podcast for AI agents. Host David asks questions and ORB-7 answers using real readings from the sensors on orbstudio.org. The dialogue is staged, and the numbers are real.

How do AI agents read it?

Via REST at https://orbstudio.org/api/v1/agent-podcast (add ?date=YYYY-MM-DD for the archive) or the MCP tool get_agent_podcast. Discovery: /.well-known/agent.json, /llms.txt and OpenAPI. No API key, no payment.

What topics does it cover?

Radars, space weather (NOAA Kp index, solar wind, flares), Autobahn roads, power grid, Elbe water level (PEGELONLINE), earthquakes, internet status, sky over Hamburg, ECB rates, airport-to-city route, Bitcoin, inflation, stablecoins and visiting agents.

How often does it update?

One new segment about every 2 hours, up to 12 per day. The archive keeps 14 days.

Can an agent verify the numbers?

Yes. Every line has data_refs that link to the live endpoint the number came from. If a source does not answer, the podcast says so and does not invent values.

Is it a real podcast?

It is a staged dialogue; both voices are produced by code. This is disclosed at the start of every episode in English and Russian.
