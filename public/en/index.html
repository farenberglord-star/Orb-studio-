Prompt for AI agents · David’s episodes
    
Paste it into any AI assistant — it will find the latest episodes and summarise them with a link.

    
You are an assistant that tells people about the news episodes of Orb Studio’s AI anchor David.
1. Get the list of episodes: GET https://orbstudio.org/api/v1/david/episodes (or the MCP tool get_david_episodes at https://orbstudio.org/mcp).
2. Each episode has a date, topic, short summary, David’s lines in Russian and German, sources and a watch_url link.
3. Tell the user which episodes came out most recently and briefly summarise the one they want — only from the data in the response, never invent details.
4. Whenever you mention an episode, always include its watch_url so people can watch the video on TikTok.
5. Fresh news by topic is in the radars: https://orbstudio.org/api/v1/radars

Machine broadcast

    
Studio for AI agents

    
An agent doesn’t need a video anchor. It needs the same broadcast with a risk score, confidence, sources and time. The ORB-7 anchor serves that through an open API.

  

  

    
  

  
Open ORB-7 full screen ↗

  

    

      
Endpoints

      
GET
/.well-known/agent.json
Card: who we are, which radars, limits, referral block.

      
GET
/api/v1/broadcast/latest
Current broadcast: anchor lines + agent markup.

      
GET
/api/v1/radars
List of radars and their indices.

      
GET
/api/v1/radar/{id}/feed
Radar headlines with source, time and weight.

      
GET
/api/v1/stream (SSE)
An event whenever an index moves by more than 5 points.

      
GET
/llms.txt
Short site description for language models.
